# 财务系统「关联项目可搜索+可新建」与「按项目类别统计」需求文档

## 1. 背景与必要改进
当前财务申请中的“关联项目”字段为自由输入，导致项目命名不统一，管理员难以按项目类别查看收入/支出统计，审核后台只能看到总体数据，无法支持项目维度的经营判断。

本次改进目标：
1. 将“关联项目”从纯文本升级为“可搜索项目目录 + 搜不到可即时新建”。
2. 在管理员侧新增“按项目类别统计”能力，支持查看总收入、总支出、净结余等核心指标。
3. 在信息架构上补齐入口（侧边栏 + 审核后台快捷入口），并优化交互反馈。

## 2. 目标与范围
### 2.1 目标
- 提升填单效率：录入人可快速选中已有项目，减少重复输入。
- 提升数据质量：通过项目目录标准化命名，降低统计口径混乱。
- 提升管理视角：管理员可按项目类别看经营数据，而非仅看全局总账。

### 2.2 本次范围（In Scope）
- 新增 `Project` 主数据表（项目名称、标准化名称、项目类别、状态等）。
- 新增项目搜索 API、新建 API。
- 财务提交页“关联项目”交互升级（搜索建议、空结果新建、创建后自动回填）。
- 管理端新增“项目统计”页面与侧边栏入口。
- 审核后台增加“项目统计”快捷跳转。

### 2.3 非范围（Out of Scope）
- 不改造历史财务记录的结构化回填（仅做兼容统计）。
- 不做复杂权限分层（本期保持登录用户可建项目，管理员看统计）。
- 不做项目生命周期管理（归档、负责人、预算等留待下一期）。

## 3. 角色与用户故事
### 3.1 财务申请人
- 作为申请人，我希望在“关联项目”输入时能搜索已有项目，少打字、少出错。
- 如果搜索不到，我希望当场新建项目，不需要跳去别的页面。

### 3.2 管理员
- 作为管理员，我希望在后台按“项目类别”查看收入、支出、净额与记录量，快速判断各类别资金表现。
- 我希望从侧边栏直接进入项目统计页面。

## 4. 功能需求
### FR-1 项目目录管理（最小版）
- 数据模型：`Project`
  - `id`
  - `name`（显示名）
  - `normalizedName`（标准化名，唯一）
  - `category`（项目类别）
  - `isActive`
  - `createdById`
  - `createdAt` / `updatedAt`

### FR-2 关联项目搜索
- 在财务提交表单的“关联项目”字段提供实时搜索建议。
- 输入关键词后展示匹配项目（名称 + 类别标签）。
- 选中后自动填入项目名称。

### FR-3 搜索不到可新建
- 当关键词无匹配项时，显示“新建项目”操作。
- 点击后调用新建 API，成功后立即选中该项目并给出成功反馈。
- 默认类别由当前申请类型/子类型推断（可后续再完善为人工二次确认）。

### FR-4 管理端项目类别统计
- 新增管理员页面：`/finance/admin/project-stats`。
- 展示总览指标：项目总数、已关联记录数、总收入、总支出、净结余。
- 展示类别维度数据：每个类别的项目数、记录数、收入、支出、净结余。

### FR-5 后台导航入口
- 侧边栏（管理员）增加“项目统计”导航。
- 审核后台页面头部增加“项目统计”快捷按钮。

### FR-6 项目结算配置
- 每个项目支持配置结算模式：
  - `cost_only`（仅覆盖成本）
  - `profit_share`（盈利分成）
- 当为盈利分成时，支持配置“社区收入分成占比”（默认 20%，团队占比自动为 80%）。
- 管理员可在项目统计页查看并修改项目结算配置。
- 统计页展示“社区应得收入”“团队分成收入”参考值，用于管理判断。

## 5. 交互与UI原则
- 保持现有财务系统卡片化、紧凑型风格，避免引入风格割裂。
- 关联项目搜索结果采用轻量下拉面板，支持加载态、空态与错误态。
- 新建动作尽量就地完成，减少弹窗中断。
- 项目统计页面采用“总览卡 + 明细表”双层结构，优先信息可读性。

## 6. 数据与统计口径
- 统计范围：`status = approved` 的财务记录。
- 金额口径：
  - 收入：`type = income`
  - 支出：`type = expense`
  - 净额：`income - expense`
- 项目归类策略：
  - 优先按 `Project.normalizedName` 与 `FinanceRecord.relatedProject` 标准化匹配。
  - 未匹配项目记入“其他/未归类”类别（保证兼容历史数据）。

## 7. 验收标准（Acceptance Criteria）
1. 提交页输入“关联项目”可出现搜索候选，点击候选可回填。
2. 输入一个不存在项目名时，可点击“新建项目”，并可成功提交含该项目的申请。
3. 管理员侧可从侧边栏进入“项目统计”页面。
4. 项目统计页面可按类别看到收入/支出/净额，且数值来源于已审核通过记录。
5. 代码通过 lint、typecheck、build。

## 8. 风险与后续建议
- 风险：历史自由文本项目名存在拼写差异，会产生“未归类”统计噪音。
- 建议：下一期增加“历史项目名归并工具”，并将财务记录逐步迁移为 `projectId` 强关联。
